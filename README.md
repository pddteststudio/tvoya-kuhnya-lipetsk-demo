# Твоя Кухня — демонстрационный сайт для Липецка

**Готовый адаптивный проект** с авторскими SVG-визуализациями, портфолио проектов и интерактивным конструктором мебели. Это независимый, **неофициальный концепт**. Авторская ссылка в футере — [@milmak11](https://t.me/milmak11).

## Что реализовано

- Стиль интерьерного бюро: айвори, ореховые и графитовые оттенки; широкие композиции, типографика и минимум обводок.
- Оригинальные SVG-визуализации: интерьер кухни, шкаф-купе, прихожая, материалы, мастерская, мебельные детали.
- Портфолио с фильтрами «Все», «Кухни», «Шкафы», «Прихожие» и раскрывающимися карточками.
- Три кейса из публикаций ноября 2026 года: кухня 3,3 × 1,9 м в Большом Самовце; шкаф высотой 2 690 мм и прихожая высотой 2 640 мм из ЖК «Геометрия». **Содержание и размеры основаны на публикациях компании, а изображения созданы как демонстрационные эскизы и не являются фотографиями этих объектов.**
- Каталог направлений: кухни, шкафы, прихожие, гардеробные.
- Конструктор: тип мебели, три конфигурации кухни, четыре цвета фасадов, длина, отделка столешницы, бюджет, встроенная техника, комментарий и предпросмотр помещения по фотографии.
- Подготовка текста заявки для копирования и самостоятельной отправки в VK. Нет регистрации, сервера, сохранения данных или автоматической отправки.
- Разделы о материалах, этапах заказа, компании, факторах стоимости, FAQ и контактах.
- Плавное появление разделов, эффекты наведения, анимации с учётом `prefers-reduced-motion`.
- Адаптивность от 320 px, SVG-значки вместо символьных стрелок, отсутствие декоративной нумерации разделов.
- Компактная рамка в футере **«Разработчик @milmak11»**.

## Как запустить

Никаких npm-зависимостей нет. Это **статический сайт на HTML, CSS и JavaScript**.

### Без установки

Откройте `preview-offline.html` в браузере — это **полная автономная версия** со встроенными CSS, JavaScript и SVG-иллюстрациями. Для копирования текста в некоторых браузерах требуется HTTPS либо локальный сервер.

### Оригинальная структура проекта

Рекомендуется запустить любой статический сервер:

```bash
python3 -m http.server 8000
```

Перейдите в браузере на `http://localhost:8000/`.

## Публикация в Vercel

1. Распакуйте архив.
2. Поместите файлы **из папки** `Tvoya_Kuhnya_Website_Vercel` в корень репозитория GitHub. Файл `index.html` должен находиться в корне репозитория.
3. В Vercel нажмите **Add New → Project**, затем импортируйте репозиторий.
4. **Framework Preset: Other**. Build Command — пусто или отключено. Output Directory — корень (`.`) при необходимости указать вручную.
5. Нажмите **Deploy**.

Предлагаемый адрес для демо: `tvoya-kuhnya-lipetsk-demo.vercel.app`. Его доступность не проверялась.

Для предпросмотра на GitHub Pages также достаточно загрузить все исходные файлы; относительные пути уже настроены.

## Перед превращением демоверсии в официальный сайт

- Получить разрешение владельца и уточнить идентификацию бизнеса, контактные данные, реквизиты, зоны работы и расписание.
- Заменить демонстрационные интерьерные SVG на фотографии **реальных работ компании**, полученные с разрешения.
- Подтвердить описания трёх проектов, названия материалов, имена специалистов и согласовать использование этих сведений.
- Получить актуальные сроки, условия бесплатного замера, доставки, сборки и гарантии. Не выводить неподтверждённые тарифы.
- Подключить официальную форму заявки и юридические документы, необходимые для обработки персональных данных.
- Только после согласования и запуска официального сайта убрать метки деморежима, `noindex` и запрет индексации.

Конструктор не рассчитывает цену и не заменяет рабочие чертежи; визуализации условны. При выборе фотографии она показывается **только локально**. В тексте копируемой заявки указывается, что изображение нужно приложить в переписке отдельно. Фотографии никогда не отправляются на сервер.
